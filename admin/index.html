Configura tu acceso

Se hace una sola vez en cada dispositivo. Tu llave de GitHub se guarda cifrada con tu PIN solo en este navegador.

¿Cómo saco mi llave?
  1. En GitHub: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nombre: panel cybercadtm. Vencimiento: el que prefieras (90 días está bien).
  3. Repository access → Only select repositories → cybercadtm.com.
  4. Permissions → Contents → Read and write. Nada más.
  5. Generate token, cópialo y pégalo aquí.
